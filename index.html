03 · IA & Open Source

Skills, hooks y herramientas para LLMs.

Open source, MIT-licensed, con tests. La base sobre la que construyo productos con IA.

block-destructive-commands

Claude Code PreToolUse hook — seguridad por defecto
Featured

Hook para Claude Code que bloquea comandos destructivos antes de que se ejecuten (rm -rf, DROP TABLE, TRUNCATE, DELETE FROM sin WHERE, git push --force). Cero dependencias, 22 / 22 tests pasan. La pieza que faltaba para usar LLMs con confianza en pipelines serios.

Shell Python MIT ↗

generate-changelog

Auto-generador de CHANGELOG.md
MIT

Script bash auto-contenido que genera un CHANGELOG.md en formato Keep-a-Changelog 1.1.0 desde el historial de git. Categoriza por conventional commits, detecta breaking changes, idempotente, se niega a correr en dirty tree.

Shell MIT ↗

claude-code-bounty-submissions

5 skills production-ready para Claude Code
5 skills

Colección de 5 skills completas enviadas a un bounty board de la comunidad. Cada una es self-contained, testeada y lista para mergear. Es la prueba de que sé diseñar productos alrededor de un LLM: prompt, SKILL.md, edge cases y tests.
